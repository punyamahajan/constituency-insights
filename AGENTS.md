# Repository Standing Rules

These rules apply to all future work throughout this repository.

1. Never read, evaluate on, or tune against the official SemEval test split except through `scripts/final_test_eval.py`. That script does not exist yet; until it is deliberately added, the official test split is off-limits.
2. Never write raw tweet text into committed artifacts, reports, or logs. Any file that contains tweet text must be Git-ignored and stored under `outputs/local/`.
3. Use fixed random seeds for every experiment, with all seeds defined in a single YAML configuration file under `configs/`. Do not define experiment seeds elsewhere.
4. Add unit tests for every new module. The existing 78 tests must continue to pass.
5. Log parameters, metrics, and artifacts for every experiment. Use MLflow once it is added to the project.
6. Report numerical results only from files generated by code. Never hardcode reported numbers in documentation.
7. Make small, reviewable commits on a feature branch. Do not commit directly to `main`.
